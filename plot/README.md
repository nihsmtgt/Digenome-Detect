# ScoreCheck

`ScoreCheck` is a Java helper program for post-processing Digenome-detect BED outputs.
It compares case and control result files, filters redundant or low-quality score points, and generates summary files for downstream analysis and visualization.

## What it does
- Load case and control BED outputs from Digenome-Detect
- Filter out sites with low scores below the minimum CLSCORE threshold
- Remove nearby redundant score points
- Filter sites with poor mapping quality based on MQ0 and clipped read counts
- Compare case/control score intervals and compute a final score cutoff
- Generate filtered BED results, plot data, and an HTML visualization

## Requirements
- Java Development Kit (JDK) 11 or later
- Web browser to view generated HTML plots

## Build
```bash
javac ScoreCheck.java
```

## Usage
```bash
java ScoreCheck [options] <case.bed|caseDir> <control.bed|controlDir>
```

## Options
- `--output <outputDir>` or `-o <outputDir>`: Output directory prefix for generated files.
- `--minimum-score <threshold>` or `-min <threshold>`: Minimum `CLSCORE` to keep (default: `7.0`).
- `--mq0-clips-threshold <value>` or `-mq0 <value>`: Remove records where ratio of `MQ0 + CLIPS` relative to `FwdHead` or `RevTail` is greater than  `threshold` (default: `1.0`).
- `--ratio-threshold <value>` or `-r <value>`: Case/control ratio threshold used to decide the final score cutoff (default: `1.0`).
- `--debug` or `-d`: Enable debug mode to print loaded scores and internal state.

## Input files
- `case.bed` or directory containing case BED files generated by Digenome-Detect
- `control.bed` or directory containing control BED files generated by Digenome-Detect

## Output files
`ScoreCheck` creates the following files in the specified output directory:

- `cases.bed`: filtered case scores after redundancy and quality filtering
- `controls.bed`: filtered control scores after redundancy and quality filtering
- `plotdata.txt`: summary table used for plotting score intervals and ratios
- `plot.html`: visualization of the score distribution and ratio analysis
- `results.bed`: final selected case scores above the computed final threshold

## Example
```bash
java ScoreCheck --output ./scorecheck_out/ \
  ./case_results.bed ./control_results.bed
```

## Notes
- If `--output` is not provided, the program may fail when writing output files.
- If the `ratioThreshold` condition is never met, `ScoreCheck` will print a warning and keep all filtered case scores above the minimum threshold.
- Input paths may be directories; all `.bed` files under the directory tree will be loaded.
