# ScoreCheck

`ScoreCheck` is a Java helper program for post-processing Digenome-detect BED outputs.
It compares case and control result files, filters redundant or low-quality score points, and generates filtered BED outputs plus a plot summary.

## What it does
- Load case and control BED outputs from Digenome-Detect
- Filter out sites below the minimum `CLSCORE` threshold
- Remove adjacent redundant score points within 10 bases
- Remove low-quality sites where `(MQ0 + CLIPS) * threshold` exceeds `FwdHead` or `RevTail`
- Determine score thresholds using the control/case ratio
- Generate filtered case/control BED files, plot data, and an HTML visualization

## Requirements
- Java Development Kit (JDK) 11 or later
- Web browser to view the generated HTML plot

## Build
```bash
javac ScoreCheck.java
```

## Usage
```bash
java ScoreCheck [options] <case.bed|caseDir> <control.bed|controlDir>
```

## Options

- `--output <outputDir>` or `-o <outputDir>`: Output directory prefix for generated files. Include a trailing slash if you want the files written into a directory, e.g. `./scorecheck_out/`.
- `--minimum-score <threshold>` or `-min <threshold>`: Minimum `CLSCORE` to keep (default: `7.0`).
- `--mq0-clips-threshold <value>` or `-mq0 <value>`: Quality filter threshold for `MQ0 + CLIPS` relative to `FwdHead`/`RevTail` (default: `1.0`).
- `--ratio-threshold <value>` or `-r <value>`: Final score cutoff uses the first threshold where `controls/cases >= ratio-threshold` (default: `0.1`).
- `--debug` or `-d`: Print loaded score records for debugging.

## Input files
- `case.bed` or directory containing cleaved sample's BED files generated by Digenome-Detect
- `control.bed` or directory containing control BED files generated by Digenome-Detect

## Output files
The program writes the following files using the specified output prefix:

- `cases.bed`: filtered case points after redundancy and quality filtering
- `controls.bed`: filtered control points after redundancy and quality filtering
- `plotdata.txt`: threshold scan summary (`threshold`, `cases`, `controls`, `ratio`, `percentage`)
- `plot.html`: HTML visualization of control/case ratio across thresholds
- `results.bed`: final selected case points above the computed score cutoff

## Example
```bash
java ScoreCheck --output ./scorecheck_out/ ./case_results.bed ./control_results.bed
```

## Notes
- `--output` should be provided as a prefix string; without it the program will write files with a `null` prefix.
- If no threshold meets the ratio condition, the final cutoff remains `0.0` and all filtered case points above `--minimum-score` are kept.
- The program prints an error and exits if input BED rows are missing required info fields or if start/end columns are not integers.
